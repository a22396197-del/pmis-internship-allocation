# User Guide & Evaluation Manual

## Portals & Test Journeys

### 1. Student Portal Experience
1. Navigate to `http://localhost:5173/login`.
2. Click **Student (Aarav - MP)** to prefill test credentials (`aarav.sharma@example.com` / `student123`).
3. View the **Overview Dashboard**: Notice personalized AI recommendations with match scores (e.g. 91%).
4. Click **Score Breakdown**: Inspect the transparent 6-factor radar and matched vs. missing skills.
5. Go to **My Profile & Resume**: Upload a PDF resume to test the automatic NLP skill extraction.
6. Submit an application and check the **Applications** timeline.

### 2. Company Portal Experience
1. Log in using **Company (Tata Motors)** (`careers@tatamotors.com` / `company123`).
2. Go to **Manage Postings**: View active listings and vacancies.
3. Click **View Ranked Candidates**: Inspect candidates sorted by match score with the transparent breakdown modal.
4. Click **Post Internship**: Publish a new vacancy with required skills and stipend.

### 3. National Admin Portal Experience
1. Log in using **Admin (PM Scheme)** (`admin@pmscheme.gov.in` / `admin123`).
2. Inspect the **National KPIs** (Registered students, participating companies, open vacancies).
3. Review the **Interactive Recharts**:
   - Skill Demand vs. Supply Gap.
   - Geographic distribution across Indian states.
4. Navigate to **Fairness Allocation Engine**:
   - Toggle affirmative regional diversity quotas.
   - Click **Execute National Allocation Run**.
   - Review live candidate assignments with full explainability.
